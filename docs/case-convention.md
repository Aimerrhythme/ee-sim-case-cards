# 案例卡规范

## 命名
- 目录：`cases/<slug>/`，slug 用小写短横线，如 `rl-step`。
- 正文：`cases/<slug>/README.md`。

## 必填字段（按顺序）

```markdown
# <中文标题>（<slug>）

> 适用课程：… ｜ 难度：★☆☆ ｜ 课时：约 xx 分钟

## 1. 目标
## 2. 接线图示意
## 3. 参数表
| 符号 | 含义 | 取值 | 单位 |
## 4. 预期曲线
- 关键特征 + 可量化指标（如 τ = L/R = 10 ms）
## 5. 常见报错
| 现象 | 原因 | 处理 |
## 6. 平台指引
### Simulink   —— 模块清单 + 求解器设置（或 simulink/ 下文件）
### MATLAB     —— matlab/ 下脚本，默认不依赖额外工具箱
### Python     —— python/ 下脚本，依赖 numpy / scipy / matplotlib
## 7. 课堂提问（可选）
## 8. 相关链接（可选）
```

## 要求
- 三个平台至少给出 **MATLAB 或 Python 之一的可运行脚本**，另外的可写步骤指引。
- 数值需自洽，预期曲线特征应能由脚本复现。
- 不引用学生个人信息；不作为毕设/课设代写模板。
